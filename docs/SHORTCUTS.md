# uWidgets Keyboard Shortcuts & Mouse Gestures

## Global System Hotkeys

Global hotkeys work system-wide even when uWidgets windows are not focused. You can enable/disable or inspect registration status in **Settings -> General -> Global Hotkeys**.

| Shortcut | Action | Notes |
| --- | --- | --- |
| `Win + Shift + W` | Toggle All Widgets | Show or hide all desktop widgets simultaneously. |
| `Win + Alt + L` | Toggle Master Lock | Lock or unlock widget dragging and resizing across the desktop. |
| `Ctrl + Shift + U` | Open uWidgets Settings | Opens and focuses the Settings window from anywhere. |

> **Note:** If another application has already registered one of these combinations, uWidgets displays a warning banner in **Settings -> General** showing which shortcut could not be claimed.

## Desktop Widget Mouse Gestures

| Interaction | Behavior |
| --- | --- |
| **Left-click & Drag** | Move a widget across the desktop (or multi-monitor workspace). Snaps to the Virtual Grid on release when enabled. |
| **Drag Bottom-Right Corner** | Resize a widget manually. Hovering the handle displays a resize tooltip. |
| **Right-click Widget** | Open the widget context menu (**Edit Widget**, **Widget Settings / Remove**, **App Settings**). |
| **Click / Double-click Text Field** | On interactive widgets (**Notes**, **Reminders**), activates inline typing without moving the widget. |
| **System Tray Icon** | Double-click or right-click the tray icon to open Settings, toggle widgets, or exit uWidgets completely. |
