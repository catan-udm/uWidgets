## 特点

11 个模块化小部件类别，提供 **26 种可自定义桌面小部件视图**，支持首次启动引导、全局快捷键与系统托盘控制。

> **文档：** [用户指南 (EN)](docs/USER_GUIDE.md) ・ [小部件目录 (EN)](docs/WIDGET_CATALOG.md) ・ [快捷键与手势 (EN)](docs/SHORTCUTS.md) ・ [故障排查 (EN)](docs/TROUBLESHOOTING.md) ・ [开发指南 (EN)](docs/WIDGET_DEVELOPMENT.md)

### 监视器
**样式**: 单项指标、仪表板、设备电量 <br>
**特点**: CPU、RAM、磁盘、网络、系统电池及蓝牙外设电量（支持悬停提示）

### 开发、财经、媒体、照片与快捷启动
- **开发 (Development)**: `GitWorkingTree`（分支、领先/落后与变更状态、一键打开编辑器/终端/文件夹）、`Docker`、`DevApps`
- **财经 (Finance)**: `Crypto`（加密货币）、`Stocks`（股票）及货币换算器 `Converter`
- **媒体 (Media)**: `NowPlaying` Windows 媒体播放控制与封面展示
- **照片 (Photos)**: `PhotoFrame` 单图展示或文件夹定时轮播相框
- **快捷方式 (Shortcuts)**: `Launcher` 自定义应用/网页/文件夹快速启动器

### 体验优化与个性化

- **新手引导向导**: 首次启动提供 4 套入门组合（*Essential*、*Developer*、*Minimalist*、*Clean Slate*）与手势引导
- **小部件管理器与配置文件**: 一览所有运行中的小部件，支持高亮定位、居中恢复离屏部件，以及保存/导出/导入 JSON 布局配置
- **全局快捷键与系统托盘**: `Win+Shift+W` 切换显示/隐藏所有小部件、`Win+Alt+L` 全局锁定、`Ctrl+Shift+U` 打开设置，`Ctrl+F` 搜索设置项
- **主题与视觉效果**: 亮色/暗色主题、8 种预设样式、强调色、单色模式、透明度与圆角调节、液态玻璃预设效果

### 尺寸

您可以为每个小部件设置 4 种预设尺寸或通过右下角手柄手动调整大小：

- 小 (2×2)
- 中 (4×2)
- 大 (4×4)
- 超大 (8×4)

### 网格

小部件可根据虚拟网格调整**位置**和**大小**。

您可以更改小部件之间的网格单元格**大小**和**边距**，或者完全禁用网格。

## 系统要求

- Windows 8.1 或更新版本 
- [.NET 8.0 运行时](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)

## 安装与快速开始

1. 下载 [最新版本](https://github.com/creewick/uWidgets/releases)
2. 解压下载后的文件并运行 `uWidgets.exe`
3. 按照 3 步**欢迎向导**选择入门组合并浏览桌面手势说明
4. *(可选便携模式)* 在 `uWidgets.exe` 同级目录创建空文件 `portable.dat`（或设置环境变量 `UWIDGETS_PORTABLE=1`），即可将数据保留在程序目录而非 `%APPDATA%\uWidgets`

## 卸载

1. 从系统托盘退出 uWidgets
2. 删除 `uWidgets` 文件夹（如未使用便携模式，同时删除 `%APPDATA%\uWidgets`）

## 贡献

uWidgets 在构建时就考虑到了模块化。<br/>
这意味着您可以使用 C# 创建自己的小部件。

查看 [小部件开发指南 (EN)](docs/WIDGET_DEVELOPMENT.md) 与 [API 参考](https://github.com/creewick/uWidgets/wiki/API)
